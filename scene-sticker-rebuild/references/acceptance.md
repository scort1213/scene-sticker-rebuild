# 验收与交付

## 贴回方式（recompose.py）

- **贴纸始终完整**，不会为了还原原图被裁掉。
- **贴放顺序**从原图推断：A 的可见部分落在 B 补出来的被挡区域里，说明 A 在 B 前面。PSD 的图层顺序和 `摆放位置.json` 用的都是这个顺序。
- **互相穿插的地方**（比如爪子搭在桌上、身体却在桌子后面），上层贴纸会盖住下层的那一小部分，和原图略有不同。默认接受这个差异。
- 前景片（把被盖住的小部分单独剪成一片，最后贴上）和底板精修片默认不出：它们都是形状零碎的小片，实体贴纸书里不好用。需要时用 `recompose.py --front-pieces`（`--board-pieces` 只对拼补模式底板有意义）。

## 独立审核

每张贴纸和底板都要经过 `review.py` 的独立审核，详见 [review.md](review.md)。审核结果是验收的主要依据；下面的看图清单用于最后的整体复查。

## 看图清单

1. **全图对照**：原图、底板、贴回效果并排看。检查位置、大小、前后关系，以及有没有漏掉的元素。
2. **差异热点**：用 `qa_sheets.py hotspots` 区分两类差异。重画细节差异（褶边形状、蝴蝶结位置）属于预期；错位、缺块、前后顺序错误、残影必须修。
3. **贴纸逐张对照**：用 `qa_sheets.py stickers` 检查身份、配色、姿态、完整度、文字。
4. **底板单独看**：是否残留角色或物体，有没有凭空出现的东西，墙角、地面边线、地形和原图是否一致，是否只剩 `board.keep` 写的内容。
5. **边缘**：贴纸边缘有没有灰底、品红或背景碎点残留。

## 参考指标

| 指标 | 用途 |
|---|---|
| 贴纸 `coverage` ≥ 0.95、`leak` ≤ 0.05 | 筛选，不达标的优先看图 |
| 贴回 `mean_abs_diff`、`frac_gt48` | 判断整体是否明显偏离，以及比较修复前后，不作为通过线 |
| `board_masks.py` 贴纸未覆盖比例 | 比例大的元素，检查贴纸是否完整、分割是否有误 |

## 交付物（export.py）

- **贴纸**：每个元素一张，按 `角色NN_标签`、`物件NN_标签` 命名。
- **分层 PSD**（主交付）：`拆分分层.psd`。图层从下到上依次是：隐藏的“原图（参考）”、“底板”、全部贴纸。每层都在原图位置、按贴放顺序排列，透明度存在图层本身，不用图层蒙版。`make_psd.py` 只按每层自己的范围写入，60 多层的万像素级大图约需 8 GB 内存、5 分钟，生成后会自动重新打开，检查图层数、尺寸和透明度。
- **其他文件**：底板、贴回效果、`摆放位置.json`（原图像素坐标和从后到前的顺序）。
- **预览与说明**：贴纸一览、三联对照图、`交付说明.md`。
- **交付时在说明里写清**：每张贴纸和底板是否通过了审核、仍未通过的项目和审核意见、分辨率和色彩模式的限制。`export.py` 会从 `qa/review_summary.json` 读取未通过的项目，自动写进说明。
