# 贴纸补全

## 输入（prep_stickers.py）

- **Image 1 编辑目标**：元素的可见像素保持原位置、原大小，放在平灰底上；被挡区域涂成品红。品红区域由三部分组成：
  - plan 里 `occluders` 的像素中靠近该元素的部分
  - 紧挨元素的画面外区域
  - `extra_zone` 手动补充的区域
- **Image 2 参考**：同一区域的原图裁切，保存为 JPEG。大 PNG 附件曾导致无界面调用卡住。
- **画布**：覆盖元素本身和附近的品红区，再扩成 3:2、2:3 或 1:1 中最接近的比例。
- 提示词要求：保持可见部分不变，只在品红区补画；输出透明背景，不要灰底、品红、地面、投影、白边，除 `text` 外不要文字。风格句来自 plan 的 `style` 和 `view`。
- 生成前先用 `qa_sheets.py inputs` 检查所有输入：品红是否只盖住真正被挡的部分；元素是否缺了耳朵或尾巴；有没有把邻居的部件当成自己的。

## 两种补全方式

- **complete（默认）**：一次调用，输入 Image 1 和 Image 2。
- **peel（剥洋葱）**：先把原图裁切里挡在前面的东西涂成品红，让模型补出“前面的东西移走后的场景”（`spec_scene.txt` → `scene.png`）；再用这张场景图作 Image 2，画出完整贴纸（`spec_peel.txt`）。适用于大部分被挡住、单独补画会画错结构或比例的物件。不要直接从场景图里用 SAM 抠：周围结构多时容易抠错，用场景图作参考再画一次更稳。

## 评分与判定（eval_sticker.py）

模型输出的位置和大小会漂移，所以先自动配准（缩放＋平移）回原图，再计算：

- `coverage`：生成结果覆盖原可见部分的比例，目标 ≥ 0.95
- `leak`：画到既不是可见部分、也不是品红区的比例，目标 ≤ 0.05
- `scale`、`shift_px`、`color_mae` 只作参考。配准会修正缩放和偏移，重画版的细节差异也会拉高色差。

这两项都达标时 verdict 为 PASS。但每张都必须看 `sheet.jpg` 和 `qa_sheets.py stickers` 的对照图，确认：身份和配色一致、姿态一致、被挡部分补得连贯合理、没有凭空出现的缺口或多余物体、文字正确。

## 常见失败与修复

| 现象 | 原因 | 修复 |
|---|---|---|
| 比例、位置、姿态都变了 | 让模型单独重画了整个元素 | 改用补画输入：可见部分锁定，只开放品红区 |
| 补出的部分不对，或被挡部分被当成空白 | `occluders` 写错，或用“相邻”代替了“遮挡” | 改 plan 的 `occluders` 后重新 prep |
| 贴纸上有凭空的缺口（如桶身被挖掉一块） | 挡在前面的东西没分给任何元素，输入里成了灰底 | 补分割那个部件（比如另一只猫的尾巴）并归给对应元素；确实无主时用 `extra_zone` 或 `fill_gaps` |
| 缺耳朵、缺尾巴，或混进了别的东西 | SAM 漏抠或混入 | 单独分割部件，`merge_masks --union` 并入；用负点排除混入的部分 |
| 大部分被挡的物件结构错误、尺寸不对 | 可见信息太少 | 改用 `method: peel` |
| 贴着画面边缘的细长元素（藤蔓）被画成一大团 | 画面外整片被标成品红，模型往里填满了 | 在 `desc` 里写清形状和粗细，并用 `reach` 调小（如 0.05），收小画面外的补画区 |
| 输出带灰底或品红残留 | 模型没有给出透明背景 | eval 会自动去掉与边缘相连的纯色底；残留明显时重新生成 |
| 调用卡住、没有任何输出 | 无界面调用偶发 | 用 `spec_short.txt` 重试一次，仍失败就停下报告 |

`fill_gaps` 会把元素凸包内、不属于任何元素的像素也当成被挡区域。它只适用于“前面有东西没被分割出来”的情况；如果是透过元素看到的背景（椅子腿之间的地面、衣架下方），开启后模型会把空隙填实。
